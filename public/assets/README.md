# BizEasy Design Foundation

This package is the starting point for the BizEasy landing-page visual system.

## Files
- `00_design_direction.md` - design read, positioning, visual thesis, constraints
- `01_color_exploration_direction.md` - six concrete color territories and selection method
- `02_design_system_foundation.md` - typography, spacing, shape, imagery, motion and usage rules
- `03_tokens.json` - implementation-ready starter design tokens
- `04_brand_guidelines.md` - concise human-readable brand/color rules
- `05_agent_kickoff.md` - copy/paste instruction for the AI coding/design agent

## Important
The selected palette in the starter tokens is a provisional implementation direction:
**Signal + Tangerine**.

The six candidate territories remain documented for future review, but the agent should build against the selected direction unless the design review explicitly changes it.
