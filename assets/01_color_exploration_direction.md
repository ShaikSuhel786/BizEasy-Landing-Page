# BizEasy - Color Exploration & Direction

## Purpose

This is the working color-decision artifact. It is not merely a swatch sheet.

Every candidate must be evaluated in the same interface composition:
logo + navigation + hero + CTA + product UI + order notification + payment state + surface.

## Existing identity

Reference anchor:
- Existing BizEasy logo blue: approximately `#4155E5`
- Brighter existing blue family: approximately `#3995FB`

These are starting references, not a requirement to make the entire website blue.

## Candidate 01 - Signal + Tangerine

- Brand blue: `#4155E5`
- Counterpoint: `#F47745`
- Deep ink: `#111522`
- Surface: `#F5F6F8`
- Secondary neutral: `#667085`

Character: energetic, optimistic, commercially confident.

Use the blue for identity and primary interaction. Use tangerine sparingly for momentum/emphasis.

## Semantic colors

These do not belong to the brand palette:

- Success: `#16865F`
- Warning: `#D59620`
- Error: `#D84A4A`
- Info: `#4187E8`

## Evaluation criteria

Score each candidate from 1-5 on:
1. Brand distinctiveness
2. Product credibility
3. Emotional fit
4. Accessibility
5. Landing-page hierarchy
6. Product UI compatibility
7. Motion compatibility
8. Ability to scale into the product

## Provisional winner

**Candidate 01 - Signal + Tangerine**

Reason:
- preserves the existing blue identity
- introduces a complementary warm counterpoint
- gives the landing page a recognizable visual tension
- avoids blue-only corporate SaaS
- avoids the beige/brass premium cliché
- leaves semantic green available for actual product states

This is provisional and should be validated against the actual hero/product composition before being treated as immutable brand law.

## Usage proportion

Starting point:

- 70% neutral surfaces
- 15% deep ink / text / dark product surfaces
- 10% BizEasy blue
- 4% tangerine
- 1% other highlights

Do not treat these as mathematically rigid. They are art-direction guardrails.
